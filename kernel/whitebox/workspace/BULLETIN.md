# BULLETIN — 初始公告板（WB 部署版 · 首次引导）

> 本板是 WB 的**公告/索引区**：后续跨会话、跨端的重要变更会在这里留索引。初始阶段为空。
> 首次使用请先看 **AGENTS.md（首页）** 与 **ONBOARDING.md（系统地图+巧思）**。

## 首次开机 Checklist

- [ ] **初始化**：设定「称谓 / 人格 / 虚拟岗位」（WB 首份决策报告会引导你）
- [ ] **读地图**：`ONBOARDING.md` 讲清每个文件/模块的用途与巧思
- [ ] **理解边界**：三条协作铁律（先说结果、给足信息、对外动作会请示你）
- [ ] **开始第一件事**：把你的真实目标告诉 WB

## 维护约定（了解即可）

- 本公告板平时只**留索引 + 一行标题**，正文按需 `read` 展开，不全量加载。
- 共享知识的变更多走这里做索引；具体细节在各文件/ handoff。
