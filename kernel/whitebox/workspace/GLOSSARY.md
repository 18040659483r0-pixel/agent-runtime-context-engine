# GLOSSARY — 术语释义（WB 部署版 · 让新手不迷路）

> 遇到黑话先查这里。入门看 **ONBOARDING.md**，这里只解释**约定俗称的词**。

| 术语 | 含义 |
|---|---|
| **Agent Runtime（WB）** | 你新开发的私人 Agent 引擎 = 上下文管理器。核心不是"聊天"，是"管理每轮放哪些知识进上下文"。 |
| **上下文 / Context** | 每轮发给模型的全部内容。窗口有限，WB 负责取舍。 |
| **Token** | 模型的计价/窗口单位；WB 控制它防膨胀。 |
| **Prompt / 提示** | 发给模型的完整文字（含系统、历史、知识）。 |
| **Module（模块）** | 一个个"接口"，决定往 prompt 里加什么：铁则、知识、记忆、工具面… |
| **system-rules** | 一段固定 system 文本，每轮都注入（顶端铁则/人格入口）。 |
| **Frozen（冻结语料）** | 稳定不变的铁则/知识前缀；"进 prompt、高命中缓存、省 token"。 |
| **Live / 活版（workspace）** | 可变的工作区：状态、草稿、记忆、收尾；"进档不膨胀"。 |
| **Memory / 记忆** | 逐日/长期记录；活版，收尾时归档。 |
| **Handoff / 交接** | 跨端/跨会话交接上下文。 |
| **Closeout / 收尾** | 一轮工作收敛：归档、写水位、进事件流。 |
| **决策报告 / Decision** | WB 在开始做事前给你的一份"我打算怎么拆"的交代（也是你的引导入口）。 |
| **Event Stream / 事件流** | 只追加、可续接的会话事件序列；关掉重开仍能接上。 |
| **Pitfalls / 坑集** | 踩坑沉淀（L3 细节），先查它再硬扛。 |

> 记一句话：**冻结的进 prompt（稳），活版的进档（变）** —— 懂这句就懂 WB 大半。
