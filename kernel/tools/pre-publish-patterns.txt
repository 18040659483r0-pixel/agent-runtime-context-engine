#
# 格式：`<kind>\t<pattern>\t<scope>\t<说明>`（TAB 分隔；`#` 开头为注释）
#   kind    = path（目录/文件名，子串）| content（内容正则，ERE 与 .NET 公共子集）| soft（只告警）
#   scope   = 这条规则**属于哪一类**（谁该用哪几条也走单一来源，不在代码里再抄一份名单）：
#             corpus    = 私有语料/快照 ⇒ 「配置与启动脚本不得引用」那条测试也用它
#             output    = 实验产物目录/文件名 ⇒ **切片里不许带**，但配置引用自己的输出目录是合法的
#             safety    = 本机路径 / 内网地址 / 凭据 / 网盘
#             judgement = 人名、用户名（软提示）
#
# 纪律：
#   1. 改这份文件 = 改**发布口径** ⇒ 必须跑一遍 `tools/pre-publish-scan.sh <目录>` 自检（含负例）。
#   2. 本文件**自身**是规则定义，必然含这些模式 ⇒ 扫描器对它**具名豁免**（见 pre-publish-scan.sh 的 ALLOW_RE）。
#   3. 凭据类模式前面带 `(^|[^A-Za-z0-9])` —— 防**假阳性**（例：`mustask-missing` 里恰好含 `sk-m`），
#      真凭据出现在行首 / 空白 / 引号 / `=` 之后，仍照旧命中。
#
