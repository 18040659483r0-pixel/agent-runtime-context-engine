## 版の規約（共通）

- **v1 以降**：シナリオや判定基準を変えたら版を上げ、そのスイートの `RUNS.md` に「どの版へ、なぜ」を記録。
- **実走記録は追記のみ**（削除しない）——1 回 1 表、日付・版・数値・発見を添える。
- 判定は**ハード**（赤/緑）と**ソフト**（記録のみ、合格条件ではない）に分ける。
