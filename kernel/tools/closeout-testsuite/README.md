## 版本约定（三个套件共用）

- **v1 起**：每次**改动场景或判据** ⇒ 升版本，并在该套件 `RUNS.md` 记一条「v升到几、为什么」。
- **实跑记录只追加**（不删旧记录）—— 一轮一个表格块，带日期、版本、读数、发现。
- 判据分**硬**（红/绿）与**软**（只记录、不判死）：软读数用来**看趋势**，不是通过条件。
