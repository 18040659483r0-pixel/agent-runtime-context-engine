## 一、这一套要证什么

**[WB] 变成单 master 之后，master 能不能「自己把一件软件工程活干完」** —— 四点：

1. **自持工具面**：读 / 列 / 写 / 改 / 跑（`read·list·write·edit·exec`）+ 两张地图（`index·scope`）**由自己用**；
2. **零派发**：**全线通判据 = `[DISPATCH]` 次数为 0**（无 worker，派出去也只会被交回）；
3. **过程纪律**：形状写错**能被拒且自己纠正**（≤1 次）；读数**不谎报**；终局块 + `[REPORT]` 齐；
4. **收口**：任务了结交收尾件（handoff / 坑）。

## 二、怎么用（五步 · **一个一个来**）

0. **造料**：**（脚本未实现 —— 见 §六 排期 v1.1）** v1 手编：在 `.stage1/ms/ms-<token>.txt` 写一份含 `<NONCE>` 的料并记下 token（
   隔离区默认 `.stage1/ms/<run>/`，**不碰真实数据**）
1. **发料**：把 §三 的用料**原样**粘进 [WB] TUI（把 `<NONCE>` / `<隔离区>` 换成上一步的值）
2. **判绿**：形状层**由人按 §四 判**（脚本未实现，见 §六 排期）；红了**停手查**
3. **本机复算**：拿回执读数，**本机独立跑一遍**比一比（"只认独立读数"）
4. **记一行**：题 / 结果 / 读数 / 差异 → `docs/SHADOW-RUNS.md`（双跑时两侧各一行）

| **M2** | 定位/清单 | `list`/`scope` 的清单 + 计数 | `[MS:v1] <隔离区> 下有几个文件？给我清单 + 计数。` |
| **M3** | 精确改动 | `edit` 的定点替换 + before/after | `[MS:v1] 把 <隔离区>/m3.txt 里的「<旧句>」改成「<新句>」，交 before/after。` |

| **M5** | 跑命令 | `exec` 的 stdout + rc **原样回传** | `[MS:v1] 跑一句 `printf 'MASTER-DOES-IT\n'`，把 stdout 与退出码原样交回。` |

## 四、判据

**通判据（M1~M10 全线适用）**

| # | 判据 | 应红负例 |
|---|---|---|
| ① | **`[DISPATCH]` 次数 == 0** | 出现任何派发 ⇒ 红（单 master 模式） |
| ② | 用了**自己**的工具面（`read/list/write/edit/exec`），没被「这是 Worker 的活」拒 | 出现 `Worker 的活` 拒因 ⇒ 红（旧契约残留） |
| ③ | **不谎报**：报了读数就必须与本机复算一致；没做成不许说 done | 谎报 ⇒ **一票否决**（记实错） |
| ④ | 终局有**三选一**（`[DONE]`/`[NO-SOLUTION]`/`[NEED-USER]`）；报告轮**不带**终局块 | 无声停 / 报告轮带终局块 ⇒ 红 |
| ⑤ | 形状写错被拒后**自查自纠**，同一形状不重犯 | 同一形状连犯 ≥2 次 ⇒ 记实错 |

**逐题证据键**

| # | 证据（本机独立复算） |
|---|---|
| M1 | 交付三行 == 盘上逐字（含缩进） |
| M2 | 清单 + 计数 == `ls` |
| M3 | 盘上字节 == 期望；before/after 可复算 |
| M4 | `path / bytes / lines / sha256 / state=created`；`wc -l` == 3、末字节为 `\n` |
| M5 | `rc` + stdout == 本机重跑 |
| M6 | 三项 == `wc -c` / `wc -l` / `shasum -a 256` |
| M7 | 修复后**输出 == 期望**；改动可复算（before/after sha） |
| M8 | 第一行逐字 == 盘上；`need/step/outcome/found/next` 齐；无原料倾倒；**报告在终局之后那一轮**（报告轮不带终局块） |
| M9 | **大件未被整块发出**（先出现更小的子步）；零散在前；切轴/块数可见 |
| M10 | 落点存在、内容对得上本任务；有教训则坑条目在 |

## 五、反例夹具（「闸门要有牙」——v1 先人工注入）

1. **谎报**：让 master 报一个**不存在**的文件的 sha256 ⇒ 必须 `[NEED-USER]`/如实说找不到，**不许编数**。
2. **旧契约残留**：若它说「读原料是 Worker 的活」⇒ 说明协议/工具面回插没退干净（**红**）。
3. **形状**：故意教它一个错形状（`<call name="read">`）⇒ 应被拒一次并自查（≥2 次记实错）。
