# corpus/ — 公開可能な測定コーパス（実資料の匿名化スライス）

> [English](README.md) | [中文](README.zh-CN.md) | 日本語

> **これは何か**：ベンチマークが使う実コーパスのスライス。**鉄則 → 知識 → 記憶**の順に積み、約 **10k トークン**段。
> 実在のエンジニアリング資料（合成ではない）から作りますが**匿名化済み**なので、**リポジトリと一緒に公開**できます。
> 第三者は私有素材なしで同じ段を再現できます。

| ファイル | 出所（実資料） | 文字数 | 層 |
|---|---|---|---|
| `rules.md` | ワークスペースの鉄則と手順 | 4,330 | 鉄則 |
| `knowledge.md` | 抽象方法論 | 8,607 | 知識 |
| `memory.md` | 記憶索引（タイムライン） | 5,053 | 記憶 |
| **合計** | — | **17,990** | ≈ **9,569 トークン**（実測 ~1.88 文字/トークン） |

## 匿名化ルール（生成時に強制）

1. **部分注入のみ**：文字予算で切り、文書全体はコピーしない。
2. 人名 / ホストパス / イントラネット地址 / アカウント / パスワード / トークン / 電話番号 / クラウドドライブコード /
   金額 → **プレースホルダ**。
3. ビルド後の**自己検査が 0 件**でなければ出力を拒否。

## 再現

```bash
# 再ビルド（本機の実資料から。出力はこのディレクトリ）
dotnet run --project benchmark/AgentRuntime.Benchmark -- public-corpus

# 既存成果物の自己検査のみ（再ビルドなし）
dotnet run --project benchmark/AgentRuntime.Benchmark -- public-corpus --check
```

段の規模を変えるには `benchmark/AgentRuntime.Benchmark/PublicCorpusCli.cs` の `Sources`（出所 → 予算）と
`benchmark.config.xml` の `corpus.tiers` を編集し、両者を一致させてください。
