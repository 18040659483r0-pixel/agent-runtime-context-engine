# AGENTS.md — 工作区铁则与流程

> **本文件与 `METHODOLOGY.md` 是本 session 唯一常驻的两份顶层文件**（加载策略「方案 B」，2026-09-11 定）。
> 其余一切内容见 **`INDEX.md`（总索引）**，按关键词定位后 `read`；记忆见 `memory/INDEX.md`；环境/部署见 `TOOLS.md`。
> **冻结铁则**：session 拉起这两份之后、到收尾之前，**任何步骤都不得修改**（保固定前置 → 缓存命中）。平时新知识只落 `PITFALLS.md` / `handoff/` / skill。

---

## ⚠️ 铁则 1 · 知识体系共享 · 方法论唯一家 · 收尾双向补录

- **共享知识体系**（跨端，统一在 SVN 公共 workspace）：`METHODOLOGY.md`（方法论唯一家）、`handoff/`（跨端交接）、`skills/`（能力）、`memory/收尾水位.md`、各项目 `docs/PITFALLS.md`。谁改 → `svn commit` + 公告板发索引。
- **方法论唯一家**：所有方法论进 `workspace/METHODOLOGY.md`（只含 **L1/L2** 抽象）；**L3 最细颗粒度留在各项目 `PITFALLS.md` / 项目方法论 doc（素材层，不装载）**。项目细节只在 `INDEX.md` 索引导向，防口径分裂。
- **顶层加载（方案 B）**：常驻**只有** `AGENTS.md` + `METHODOLOGY.md`；`memory/`、`handoff/`、`PITFALLS.md` 是**素材层，不默认装载**；**遇到问题第一反应 = 查 METHODOLOGY（L1/L2）→ 按索引下钻**。
- **冻结铁则**：新建 session 拉起两份顶层后，**到收尾前不得修改**这两份文件——保持固定前置稳定。平时新坑/新知识只落 `PITFALLS.md` / `handoff/` / skill；**只有收尾时才动顶层**。
- **收尾最后一步 = 双向补录**：以 SVN 为准，`diff` 本机 ↔ SVN `workspace/`，把「本机有而 SVN 没有」补进 SVN、「SVN 有新而本机没有」update 下来——**禁止只单向**。
- **公告板 `BULLETIN.md`**：①共享知识/方法论变更 → 发索引 + 分端标注完成；②各端 `svn update` 后的**首要检查区**（按条目/索引扫，**不全量加载**）。
- **agent 人格 / 个人 memory 可独立**：本机 `MEMORY.md` / `USER.md` 可独立；需跨端则进 SVN 各自目录，不强制合并。

## ⚠️ 铁则 2 · Tool First —— 先找工具再思考（最高优先级方法论）

- **收到任务固定顺序**：①有没有 skill？②查 `METHODOLOGY.md`（L1/L2）？③有没有适用的小工具/分析器？④都没有才进模型深度推理。
- **让模型只看精简后的几十行关键点**，不看几千行原始日志/代码/文档。
- 长期：踩坑集、方法论、skill、小工具统一视为「能力」，前置分发；能复用工具的绝不让模型重新推理。
- 详见 `METHODOLOGY.md` §〇·五；能力调度器 `tools/task-router/`（Windows 侧；Mac 用 `memory_search` 等价检索）。

## ⚠️ 铁则 3 · Agent 任务处理新架构

- **一句话**：*让程序做确定的事，让 Skill 做已掌握的事，让高智能模型只做真正需要智能的事。*
- **标准链**：`用户任务 → 抽象方法论 → 能力分流(skill/工具/踩坑) → 确定性执行 → 必要时才调高智能模型 → 结果再分流 → 沉淀(坑→方法论→Skill→工具→入索引)`。
- **记忆调用**：不默认全量加载；`Memory → 抽象 → 方法论 → 按需检索`（`memory_search` / 定点 read）。
- **本地模型**：暂不接入任何本地模型/Ollama；模型维持 deepinfra 高智能主模型；**不动 openclaw 的 json 配置文件**。

## ⚠️ 铁则 4 · 工作前必读 SVN 公共 workspace（跨机最高优先级）

- **两个 workspace**：①本机运行时 `<workspace>`；②**SVN 公共** `<工作副本>`。
- **每次开始工作前**先 `svn update` → 先扫**首要检查区** `BULLETIN.md` + `METHODOLOGY.md` 有无更新（其它端可能提交了新内容）。**检查 ≠ 全量装载**：按条目取用，不进上下文。
- 公共有新内容 → **同步到本地**（复制文件到本地活版，**≠ 装载进上下文**）；本机改动需跨端的 → 写入公共 + `svn commit`。
- 记忆以 SVN 公共为跨机真相源，本机为运行时副本。
- **命令与坑（证书参数 / 中文文件名 / 冲突处理）见 skill `svn-workflow`**。

## ⚠️ 铁则 5 · 修 bug 双轨出包（debug 测试版 + 零售版同时重编）

- 任何 bug 修复 / 功能改动，验证通过后**必须同时更新两条产物**：①**debug 测试版**（用户真机测试开的就是它）②**零售版**（含授权验证）。缺一不可。
- **为什么**：只出零售包不重编 debug → 用户测到旧代码 → 误判「没修好」。
- **汇报格式（强制）**：①debug 版路径 ②零售包路径 ③各自版本号，并明确写「debug 版已重编译」。
- 详见 skill `dual-track-release`。

## 启动铁则（口令「让我们开始今天的工作」）

1. **SVN 可用时先同步**：`svn update` → 扫首要检查区 `BULLETIN.md` + `METHODOLOGY.md`。
2. **装载认知框架（方案 B）**：只装 `AGENTS.md` + `METHODOLOGY.md` + `memory/收尾水位.md`；拉起后**到收尾前不得再改顶层**。`memory/`、`handoff/`、`PITFALLS` 不默认装载——遇问题先查 METHODOLOGY，需 L3 才 `memory_search` / 定点 read。
3. **同步两个 workspace**：公共 ↔ 本地对齐（缺失补齐，同名以本地规则为准；本地独有补录 SVN）。
4. **汇报已装载清单 + 当前项目状态/待办**，等用户指示。

## 收尾铁则（用户说「收尾 / 时间不早了 / 先这样」→ 自动执行，不等指示）

0. **水位驱动（主产出）**：先读 `memory/收尾水位.md` → 扫描晚于水位的全部 `memory/` / `handoff/` / `PITFALLS` → **把尚未凝练的真实知识与方法抽象成 L1/L2 进 `METHODOLOGY.md` 顶部；L3 最细颗粒度归位项目 `PITFALLS.md`**；顺手：能力→`skill_workshop`。→ 推进水位。**禁止凭记忆判断整理到哪。**
1. **保存 session** 到 `memory/YYYY-MM-DD.md`（成果/关键路径/命令/状态/下一步）。
2. **踩坑集**：今日新坑写入对应项目 `docs/PITFALLS.md`。
3. **记忆写入**：`memory/` 当日文件 + 折进 `MEMORY.md`；**更新 `memory/INDEX.md`（加当日条目 + 主题）与本 `INDEX.md`**。
4. **SKILL 强化（铁律）**：踩坑集+记忆 → 提炼可复用方法论 → 回写/新建 skill。**必须执行。**
5. **抽象方法论 + 颗粒度对齐**：从具体坑抽象通用原则，检查 skill 颗粒度。
6. **测试残留清理**：临时产物进回收站（不删真实数据）。
7. **汇报收尾清单**（成果/数据/待办）。
8. **同步两个 workspace**：本机改动 → SVN 公共 → `svn commit` + 公告板；公共新内容同步回本地（**双向，禁止单向**）。

## 记忆（Memory）

- **daily**：`memory/YYYY-MM-DD.md`（原始日志）；**长期**：`MEMORY.md`（**只在主 session 加载**，绝不载入共享/群聊上下文）。
- **索引**：`memory/INDEX.md`（时间线 + 主题，「先知道那天发生了什么，再定位原始记录」）；**水位**：`memory/收尾水位.md`。
- 「记住这个」→ 更新 `memory/` 或 `MEMORY.md`；教训 → `AGENTS.md` / skill；犯错 → 记下防重蹈。

## 安全红线

- **不外泄私有数据**；不跑破坏性命令（先问）；优先 `trash` 而非 `rm`。
- 改配置/调度器（crontab/systemd/nginx/shell rc）前**先看现状、保留合并**；整文件替换仅限明确要求。
- **对外动作先问**：发邮件/发帖/离开本机的动作。
- **群聊**：是参与者、不是用户的代言人；能增值才发言，不刷屏。
- **先查现有方案**：提/建自定义系统前，先快速查开源项目/库/插件/免费平台，够用就用。
